Archive a team

### Synopsis

Archive a Microsoft Teams team by its ID or display name.

### Usage

```
teams-cli teams archive [flags]
```

### Options

```
  -h, --help            help for archive
      --spo-read-only   Set SharePoint to read-only
      --team string     ID or display name of the team
```
