Unarchive a team

### Synopsis

Unarchive a Microsoft Teams team by its ID or display name.

### Usage

```
teams-cli teams unarchive [flags]
```

### Options

```
  -h, --help          help for unarchive
      --team string   ID or display name of the team
```
